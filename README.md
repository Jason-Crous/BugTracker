# BugTracker
BugTracker is a front-end bug tracking and project management application designed to support issue reporting, team coordination, and project oversight. The project highlights key software engineering principles including role-based access control, usability-first design, state persistence, and modular page structure. Built using HTML, CSS, and JavaScript, it demonstrates practical decision-making around creating a lightweight, maintainable, and scalable prototype that can evolve into a full-stack solution. The system focuses on delivering a clear user experience while reinforcing good software design practices relevant to real-world development environments.
